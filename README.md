# aaamini.github.io

Personal academic homepage. Plain static HTML generated by a single Python
script — no Jekyll, no npm. The generated site lands in `_site/` and is
deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to
`main`.

## Layout

```
data/
  papers.bib      single source of truth for publications (shared with the CV)
  site.yml        name, nav, links, research interests
  news.yml        news items shown on the homepage
  classes.yml     course list for /teaching/
  students.yml    current students and alumni
content/
  index.md        homepage bio
  research-faq.md, pte-policy.md
  notes/*.md      one file per note, served at /notes/<slug>/
templates/        Jinja2 templates (base.html is the page shell)
assets/           copied verbatim to /assets/ (css, js, images, paper PDFs)
teaching/         course pages: *.md rendered at their `permalink`,
                  everything else (PDFs, grade stats, code) copied as-is
build.py          the whole generator
```

## Common edits

**Add a paper.** Append a BibTeX entry to `data/papers.bib`. Standard fields
render as usual; these extra fields drive the website and are ignored by
LaTeX/bibtex when the same file is used for the CV:

```bibtex
abbr     = {ICLR},          % venue badge ("Preprint" gets its own color)
arxiv    = {2406.10686},    % arXiv id -> link
pdf      = {paper.pdf},     % file in assets/pdf/, or a full URL
code     = {https://github.com/...},
abstract = {Shown in an expandable fold.},
selected = {true},          % feature on the homepage
supp     = {supp.pdf}, slides = {...}, poster = {...}, website = {...}
```

**Add news.** Add a dated item to `data/news.yml`.

**New course / quarter.** Add an entry to `data/classes.yml` (set `active:
true`, demote the old one to `false`) and drop a course directory into
`teaching/` containing a markdown file with `permalink: /teaching/<short>` in
its front matter. Sibling files (PDFs, HTML) are published next to it.

**Write a note.** Create `content/notes/<slug>.md` with `title:` and `date:`
front matter. Math works with `$...$` and `$$...$$`.

**Students.** Edit `data/students.yml` (`alum: true` moves someone to the
alumni table; `coad`, `job_title`, `loc`, `link` are optional).

## Local preview

Uses [uv](https://docs.astral.sh/uv/) for dependencies (no manual venv step —
`uv run` creates `.venv`, installs from `uv.lock`, and provisions a matching
Python on first use):

```sh
uv run build.py --serve     # http://127.0.0.1:8000
```

`--serve` rebuilds automatically when any source file changes. A plain
`uv run build.py` builds once into `_site/`. To change dependencies, edit
`pyproject.toml` then run `uv lock` (commit the updated `uv.lock`).

## First deployment

1. Create a GitHub repo named `aaamini.github.io`, push this directory to it
   (branch `main`).
2. In the repo: Settings → Pages → set "Source" to **GitHub Actions**.
3. Every later push rebuilds and deploys automatically (you can also edit
   `data/*.yml` or `papers.bib` directly on github.com).

## Redirect from the UCLA address

URL paths are unchanged from the old site, so a path-preserving redirect
migrates every deep link. In `public_html/` on the department server, put an
`.htaccess` with:

```apache
RewriteEngine On
RewriteRule ^(.*)$ https://aaamini.github.io/$1 [R=301,L]
```

If `.htaccess` is not allowed, fall back to a meta-refresh stub `index.html`
pointing at https://aaamini.github.io.
