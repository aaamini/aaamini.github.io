---
title: 'How to change the name of a course in Canvas?'
date: 2023-04-04
---
If you've been struggling to remember how to change the name of a course in Canvas, you're not alone. Please note that the option to change the name may be disabled, and it can only be done from the Settings in the left panel when you select the course.

However, you can change the **nickname** of the course instead, which can be just as helpful. Here's how:

1. Go to the [Bruin Learn](https://bruinlearn.ucla.edu/) website.
2. Choose "Dashboard" from the left panel.
3. Scroll down to see the course cards, which may be located below the notification cards.
4. Click on the ⋮ icon on the course card, and with a few attempts, you should be able to change the nickname there.

With these steps, you can quickly and easily change the course nickname without having to search for the option to change the name.
